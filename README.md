# TRIPVERSE — Smart Travel Explorer
A frontend-only college laboratory project built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `TripVerse` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. No backend, database, build process or API key is required.

## Pages
- Home, destinations, packages, booking, traveller profile, gallery
- Login and registration demos
- Checkout demo, travel magazine, interactive lab, HTML5 forms lab

## Notes
- All bookings, login, registration and checkout interactions are demonstrations only.
- Saved destinations and theme preference use browser LocalStorage.
- Destination photography and Google Fonts load from their public image/font hosts; an internet connection is needed for those remote visual assets. The site itself has no API/backend dependency.
- Never enter real card or payment details in the checkout demo.
